## 🧩 About

**Caliber Companion** is a curated list of Caliber open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD study, operator info panels
- **Quality-of-Life Helpers** — loadout notes, config presets, session trackers
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Session Helpers
- Operator Notes — browse roles, abilities, and gear in one panel
- HUD Overlay — readable stats overlay for study sessions
- Loadout Presets — organize and compare custom loadouts
- Session Timer — track practice and review runs

### 🎨 Catalog & Cosmetics
- Cosmetic Catalog — browse skins, colors, and emblems
- Preset Notes — organize favorite appearance sets
- Visibility Tweaks — clearer outlines for study footage

### 🏋️ Practice Layout
- Range Notes — segment study on any training map
- Movement Notes — review traversal timings in offline drills
- Team Drill Notes — chain coordinated maneuvers in private lobbies
